Private workflow automation

Fleebee Statement Downloader is a private utility that helps its owner collect expected bank-statement PDF attachments from Gmail and store them securely on the owner's computers for later review in Fleebee.

Limited, owner-operated access

This application is not offered as a public email service. It is operated by the Gmail account owner for the owner's own statement-processing workflow.

How the application works

1. Match

The application checks for messages that carry a dedicated Gmail label and match the configured bank sender, subject, and PDF attachment rules.

2. Validate

It verifies attachment type, sanitizes filenames, and tracks identifiers and cryptographic hashes so the same attachment is not downloaded twice.

3. Store locally

Matching PDFs are downloaded to protected storage controlled by the owner. They are not published or made available to third parties.

Gmail access

The application requests read-only Gmail access solely to locate and download expected statement attachments. It does not send email, delete messages, change message content, or use Gmail data for advertising.

Data protection

  • OAuth credentials and tokens are stored in restricted files on computers controlled by the owner.
  • Downloaded statements remain in private local storage until the owner removes them.
  • Gmail data is not sold, shared with advertisers, or used to train generalized artificial-intelligence models.
  • The owner can revoke access at any time through Google Account security settings.
